# DSTRKT — streetwear storefront

Simplicity is style. A full storefront for the DSTRKT fashion brand: shop, collection, lookbook, product pages and cart.

![DSTRKT](docs/media/hero.png)

Editorial black-and-white layout, oversized type, and fast static pages with no framework.

**[Visit the store →](https://dstrkt-site.vercel.app)** · HTML · CSS · vanilla JS

---

## Pages

- **Home** with a rotating hero
- **Shop**, **Collection** and **Lookbook**
- **Product pages:** heavyweight hoodie, oversized graphic tee, tech cargo pants, tech windbreaker
- **Cart**, **Account**, **Search**, **Locale** picker, **Updates** and **About**

## Run it

It's a static site. Open `index.html`, or serve the folder:

```bash
npx serve .
```

## Built with

HTML, CSS and vanilla JavaScript (`site.js`), deployed on Vercel.
